# Stories Come Alive — ভিডিও লাইব্রেরি ওয়েবসাইট

ক্যাটাগরি অনুযায়ী সাজানো ভিডিও লাইব্রেরি। ভিডিও থাকে YouTube-এ, সাইটে Embed হয়ে চলে।
ভিডিও দেখতে হলে দর্শককে **অ্যাকাউন্ট খুলে লগইন** করতে হয়।

A category-wise video library website. Videos live on YouTube and play embedded.
Watching requires a free user account (register + login).

---

## যা যা আছে / Features

- 📚 ক্যাটাগরি অনুযায়ী ভিডিও (রোমান্স, হরর, থ্রিলার, ফ্যান্টাসি, সিরিজ…)
- 🔐 রেজিস্ট্রেশন + লগইন সিস্টেম — লগইন ছাড়া ভিডিও চলবে না
- 🎉 রেজিস্ট্রেশনের পর স্বাগত পেজে **YouTube সাবস্ক্রাইব** ও **Facebook Follow** বাটন
  (লিংক অ্যাডমিন প্যানেল থেকে বসাতে হয়; লিংক না দিলে বাটন দেখাবে না)
- ❤️ প্রতিটি অ্যাকাউন্টের নিজের **পছন্দের তালিকা** (favorites)
- 🛠️ অ্যাডমিন প্যানেল: ভিডিও যোগ/এডিট/মুছুন (শুধু YouTube লিংক পেস্ট করলেই হয়),
  ক্যাটাগরি সাজানো, ব্যবহারকারীর তালিকা
- ✏️ **সাইটের নাম ও লোগো অ্যাডমিন প্যানেল থেকেই বদলানো যায়** — কোড ছোঁয়ার দরকার নেই

## সাইটের নাম / লোগো বদলাবেন যেভাবে (কোড ছাড়াই)

1. সাইটে গিয়ে নিচে **অ্যাডমিন** লিংকে ঢুকুন → পাসওয়ার্ড দিয়ে লগইন
2. **সেটিংস** পেজে যান
3. নাম বদলাতে: "সাইটের নাম" ঘরে নতুন নাম লিখে **সেভ করুন** — হেডার, পেজের টাইটেল,
   ফুটার — সব জায়গায় সাথে সাথে বদলে যাবে
4. লোগো বদলাতে: একই পেজে **"সাইটের লোগো"** অংশে নতুন ছবি (PNG/JPG) বেছে
   **লোগো আপলোড করুন** চাপুন — পুরো সাইটে নতুন লোগো দেখাবে
   (ভুল হলে "ডিফল্ট লোগোতে ফিরুন" চাপলেই আগের লোগো ফিরে আসবে)
5. একই পেজে YouTube চ্যানেল আর Facebook পেজের লিংকও বসাতে/বদলাতে পারবেন

## প্রথমবার চালু করার সময় যা লাগবে / First-run setup

1. সাইট প্রথমবার খুললে `/admin`-এ গেলে **অ্যাডমিন পাসওয়ার্ড তৈরি** করার পেজ আসবে —
   নিজের পছন্দের পাসওয়ার্ড দিন (কমপক্ষে ৬ অক্ষর)।
2. অ্যাডমিন → **সেটিংস**-এ গিয়ে বসান:
   - YouTube চ্যানেলের লিংক (যেমন `https://www.youtube.com/@YourChannel`)
   - Facebook পেজের লিংক (যেমন `https://www.facebook.com/YourPage`)
   - চাইলে সাইটের নাম ও লোগো
3. অ্যাডমিন → **ভিডিও**-তে গিয়ে YouTube লিংক পেস্ট করে ভিডিও যোগ করুন।

## Deploy (GitHub → Render)

1. এই ফোল্ডারটা GitHub-এ আপলোড করে একটা রিপো বানান।
2. Render.com → **New → Blueprint** → রিপোটা সিলেক্ট করুন (`render.yaml` নিজে থেকেই সেটআপ নেবে)
   অথবা **New → Web Service** → Build: `npm install`, Start: `npm start`।
3. Deploy শেষ হলে সাইটের লিংক পাবেন (যেমন `https://stories-come-alive.onrender.com`)।

> ⚠️ **Android সতর্কতা:** চ্যাট থেকে ডাউনলোড করা ZIP/ফাইলের নামের আগে অনেক সময়
> লম্বা একটা শিরোনাম জুড়ে যায়। GitHub-এ তোলার আগে File Manager-এ রিনেম করে
> ফোল্ডারের নাম হুবহু **vyrx-library-deploy** (আর ভিতরের ফাইলের নামগুলোও ঠিকঠাক)
> আছে কিনা মিলিয়ে নিন — নাম বদলে গেলে আপলোড/Deploy-এ সমস্যা হতে পারে।

> ℹ️ **Render ফ্রি প্ল্যানের সীমা:** ফ্রি সার্ভার ~১৫ মিনিট ব্যবহার না হলে ঘুমিয়ে যায়
> (প্রথম ভিজিটে জাগতে কয়েক সেকেন্ড লাগে), আর ফ্রি প্ল্যানে ডাটাবেস স্থায়ী নয় —
> সার্ভার রিস্টার্ট/নতুন Deploy হলে অ্যাকাউন্ট, ভিডিও, সেটিংস রিসেট হতে পারে।
> স্থায়ী ডাটার জন্য পরে পেইড প্ল্যানে persistent disk লাগবে।

## লোকাল টেস্ট / Run locally

```bash
npm install
npm start
# http://localhost:3000  •  Admin: http://localhost:3000/admin
```

## গঠন / Structure

```
src/server.js   — সব পেজ ও অ্যাডমিন প্যানেল (Express)
src/db.js       — SQLite ডাটাবেস (node:sqlite), সিড ক্যাটাগরি ও সেটিংস
public/         — styles.css, app.js, logo.png (ডিফল্ট লোগো — মাইক+বই আইকন), banner.jpg (হিরো আর্টওয়ার্ক)
render.yaml     — Render blueprint
```
